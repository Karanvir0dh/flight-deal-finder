# Providers

The app uses legitimate API access only.

- SerpApi Google Travel Explore: broad anywhere-style discovery.
- SerpApi Google Flights: detailed route/date results.
- Amadeus Flight Inspiration Search: cached destination discovery.
- Amadeus Flight Offers Search: detailed published fare search.
- Mock provider: deterministic local development and tests.

No Selenium, Playwright, Puppeteer, browser fingerprinting, CAPTCHA bypass, residential proxies, Google Flights HTML scraping, or undocumented Google endpoints are used.
